真实用户生成器

为测试开发批量生成自洽的假用户：同一个人的姓名、用户名、邮箱互相对应，生日与年龄对应，地址的省 / 市 / 区互相对应。填同一个 Seed（随机种子），每次生成的都是同一批人，测出的 bug（程序错误）可以直接复现。

导出后怎么用

    

      

        
JSON — 喂接口 / 前端 Mock（模拟数据）

        
下载后放进项目当夹具（Fixture，测试固定数据），或用 fetch / Postman 批量 POST 到你的注册接口测压测和校验。

      

      

        
CSV — Excel 看 / 后台批量导入

        
带 UTF-8 BOM（字节顺序标记），Excel 双击打开不乱码；大多数管理后台的「批量导入用户」吃的也是这个格式。

      

      

        
SQL — 直接灌进测试库

        
生成的是 INSERT INTO users (...) 语句，默认表名 users，在导出文件里改成你的表名即可执行。

      

    

  


  
生成逻辑参考 Faker（假数据生成库）的思路在本页内实现，数据池为中文姓名 / 城市 / 职业词库。
所有数据均为虚构，与真实个人无关。
