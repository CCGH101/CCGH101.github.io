小工具

一些随手做的小工具，打开就能用，不用注册，所有生成都在本地完成。

01 随机账号 · 密码 · 名字生成器
一次生成成套组合：单个英文词名字 + 10 位以内短账号（可加自定义后缀）+ 特殊字符只有「.」的密码。
 → 02 Krea2 提示词生成工具
点选媒介、风格、主体、场景、光线等分类，拼出 Krea2 自然语言提示词，带冲突检查、智能随机 / 补齐和 LoRA 推荐，一键复制。
 → 03 Illustrious 插画系提示词生成工具
Illustrious 版：点选拼出 Danbooru 风格英文标签串，带负面提示词区、冲突检查和 Illustrious LoRA 推荐，复制即可喂进 ComfyUI / WebUI。
 → 04 真实用户生成器
为测试开发批量生成自洽的假用户：姓名、用户名、邮箱、生日年龄、地址互相对应，同一随机种子可复现，可导出 JSON / CSV / SQL。
