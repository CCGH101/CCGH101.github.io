这是 Illustrious（插画系 SDXL 底模）版：输出是 Danbooru（标签库）风格的英文标签串，不是自然语言句子 — Illustrious 吃标签，标签顺序按 画质 → 主体 → 外貌 → 服装 → 动作 → 场景 → 光线 → 收尾 排好，复制即可喂进 ComfyUI（工作流界面）/ WebUI。随机和补齐是冲突感知的：逐类生成、每挑一条先过冲突检查；「智能补齐」以你已选内容为锚，只补未选类别。负面提示词（Negative Prompt，负面词）单独成区 — Illustrious 靠负面词压画质崩坏，和 Krea 系的正向改写不是一回事。

    LoRA 配套推荐

    主组合只用 31 个已核实的真实 Illustrious LoRA（2026-11-18 经 Civitai 官方 API 逐条核对模型 ID / 版本 ID / 真实文件名 / 触发词，下载量为当日 API 数据）· 卡片上有真实文件名＋Civitai 下载链接，照着就能找到 · 每个 LoRA 都是可选的：点卡片（或卡上的开关）就能取消，取消的不计入复制 / 导出，再点一次恢复 · 同类其他已验证 LoRA 列在下方可替换
    已选内容里还没有「媒介画风」或「主体」类词条 — 先选其中一项，这里会自动按匹配度排出最适合挂的已验证真实 Illustrious LoRA（带真实文件名和 Civitai 下载链接）、推荐权重和触发词（Trigger Word，触发词）。

    Illustrious 挂 LoRA 的规矩：画风类只挂 1 个（两个画风 LoRA 对冲会糊）；细节 / 光影 / 滑杆类可以叠，但总权重建议 ≤ 2.5。滑杆类（Slider，滑杆 LoRA）权重可正可负：正数往一头推、负数往反方向推。复制出去的清单每条带 <lora:文件名:权重> 语法，粘到正向提示词末尾或 ComfyUI 的 LoRA 加载节点都能用；带触发词的卡点「填入触发词」会自动写到上方触发词框。

    复制 / 导出只包含已加入的已验证 LoRA，每条带真实文件名＋Civitai 下载链接
    可替换备选 — 同一类里其他也匹配的已验证真实 LoRA，按匹配度排在后面，点「换上」替换主组合里同类的那一个

    用法提醒：Illustrious 是标签模型：画质词只放开头一串、主体人数先定（1girl / solo 别和多人标签混着写）、发色瞳色各只写一个，写重了模型会折中出怪色；服装要精确到底 — 整套选一套、鞋袜分开选、配饰写清件数，模型对「类别名」没有想象力，只认标签。负面词别贪多，默认组合够压住崩手和低画质；负面里放了 blurry 就别再选浅景深虚化。出图前先看一眼上方「匹配检查」：硬冲突清零再复制，翻车率会低很多。
